# ProNet — концепция сайта

Премиальная концепция сайта для интернет-провайдера ProNet (provodov-net.ru).

## Как открыть
Откройте `index.html` в браузере — сервер не нужен (three.js лежит в `vendor/`).

## Где менять данные
Все тарифы, цены, телефоны и ссылки — в объекте `CONFIG` в начале `app.js`.
Данные взяты с provodov-net.ru (ноябрь 2026).

## Подключения
- **Оплата** — форма отправляется в биллинг UTM5 на `https://provodov-net.ru/payment`
  (те же поля, что на текущем сайте: `AccountID`, `Summa`, `PaymentType` = `AlfaBankSBP` / `AlfaBank`).
  Отключить: `CONFIG.payment.action = ''`.
- **Заявка на подключение** — `CONFIG.orderEndpoint`. Пока пусто — демо-режим без отправки.
  На текущем сайте форма защищена токеном Joomla, поэтому нужен свой обработчик (PHP/CRM/Telegram).

## Файлы
- `index.html` — разметка
- `style.css` — стили (фирменные цвета #2993D1 / #162C4A, шрифт Manrope)
- `app.js` — данные и интерактив
- `scene3d.js` — 3D: волна частиц (первый экран) и оптоволокно (технологии)
